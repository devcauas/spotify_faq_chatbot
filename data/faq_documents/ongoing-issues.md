# Problemas atuais

A página “Ongoing Issues” (Problemas atuais) da nossa Comunidade tem todos os relatórios de problemas específicos do app. Ela é usada para informar nossos desenvolvedores, que vão tentar corrigir tudo o mais rápido possível. É também onde publicamos atualizações sobre cada problema. Se você perceber que algo não está funcionando como deveria, busque ou navegue na página para ver se o erro já foi reportado. Caso encontre seu problema e o status dele for “Under Investigation” (Sob investigação), clique em +VOTE para participar do tópico. Acessar página de problemas atuais
Você também pode acessar @SpotifyStatus para se informar sobre possíveis problemas em aberto.
