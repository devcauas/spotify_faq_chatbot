# Sugira um recurso

Para compartilhar uma ideia para um novo recurso no aplicativo Spotify ou alterações em um existente:
1. Acesse o quadro de ideias na comunidade.
2. Digite o título da sua ideia.
3. Percorra a lista e verifique se uma ideia semelhante foi postada. Em caso afirmativo, adicione seu voto para mostrar seu apoio.
4. Se uma ideia semelhante não tiver sido publicada, vá para o final da lista para enviar sua ideia.
Observação: você precisa fazer login com seus dados do Spotify para votar ou enviar uma ideia.
Quando uma ideia recebe votos suficientes, ela é enviada para as equipes do Spotify para revisão.
