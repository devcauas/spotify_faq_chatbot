# Pastas de playlists

As pastas de playlists são uma ótima maneira de organizar suas playlists.
Você precisa usar o app para computador, o Web player ou o app móvel para criar essas pastas, mas elas são exibidas em todos os dispositivos.

## Crie pastas de playlists

Para: computador, web player e dispositivos móveis
1. Acesse Sua Biblioteca "Coleção".
2. Selecione "Mais" na parte superior.
3. Selecione Pasta.
4. Dê um nome à pasta e aperte Enter.

## Adicione uma playlist ou uma nova pasta


## Computadores e Web player

Para adicionar uma playlist:
- Selecione, arraste e solte uma playlist em uma pasta
- Em uma playlist, selecione "3 pontos na horizontal" e escolha Mover para a pasta
- Outra opção é clicar com o botão direito em uma pasta e selecionar Criar playlist
Também é possível criar pastas dentro de pastas. Para fazer isso:
- Clique com o botão direito em uma pasta e selecione Criar pasta
- Você também pode clicar em "Mais" no topo da pasta e seguir as etapas para criar uma nova
Para mover uma playlist ou pasta para outro local, clique com o botão direito nela e selecione Mover para pasta.

## Celular

Para adicionar uma playlist:
- Na playlist, selecione "3 pontos na horizontal" e escolha Adicionar à pasta
- Ou selecione a pasta e clique em "Mais" e escolha Playlist
Também é possível criar pastas dentro de pastas. Para isso, selecione a pasta, clique em "Mais" e escolha Pasta.
Para mover uma playlist ou pasta para outro local, clique e segure nela e selecione Mover para a pasta.
