# Como entrar no Spotify com seu número de telefone

Quando você se inscreve com seu número de telefone, o login é feito com um código que enviamos para seu celular, então não é preciso gravar uma senha.

## Não consegue fazer login com o número de telefone?

Observação: não é possível usar seu número de telefone para fazer login no app para computador.
Se aparecer a mensagem “Tente de novo”, é provável que você tenha inserido o número incorretamente. Verifique o número e tente de novo.
Se o código de verificação não estiver funcionando, verifique o número e tente de novo ou insira novamente o seu número de telefone para gerar um novo código.
Observação: existem várias maneiras de se inscrever. Por exemplo, usando um e‑mail, um número de telefone, a Apple ou o Google. Tente fazer login usando essas opções para localizar sua conta.

## Não recebeu um código de verificação?

Pode levar alguns minutos se seu sinal estiver ruim.
Se estiver demorando muito, insira seu número de telefone de novo para gerar um novo código. Verifique se você inseriu o número corretamente.

## Entrar no app para computador

Não é possível usar seu número de telefone para fazer login no app para computador. Crie uma senha do Spotify para entrar usando um endereço de e‑mail:
1. Faça login na página da sua conta usando seu número de telefone.
2. Clique em EDITAR PERFIL e adicione um endereço de e-mail à sua conta.
3. Use seu endereço de e-mail para criar uma senha.
