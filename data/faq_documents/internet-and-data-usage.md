# Internet e uso de dados

O Spotify precisa de uma conexão de dados móveis ou Wi-Fi para funcionar.

## Dados móveis

É melhor usar o Wi-Fi do que os dados móveis.
Se você não tiver Wi-Fi, o app usará seus dados móveis.

## Reduzir o consumo de dados

Isso reduz o uso de dados do app, que passa a mostrar menos imagens e diminui a qualidade do áudio.
1. Clique na sua foto de perfil na parte superior.
2. Clique em Configurações e privacidade "Configurações".
3. Clique em Economia de dados e modo offline.
4. Ative a Economia de dados.
Dica: em Downloads e streams, você também pode mudar para Reproduzir apenas o áudio e/ou Apenas o áudio dos podcasts com vídeo é baixado. Assim, os programas que você ouvir ou baixar não vão incluir vídeos.

## Outras maneiras de reduzir o consumo de dados móveis:

- Se você for Premium, baixe músicas para ouvir offline. Dica: para que o app só baixe quando estiver conectado ao Wi-Fi, acesse as configurações do app (em Economia de dados e modo offline) e desative a opção Baixar pela rede celular.
- Veja qual opção está selecionada para a Qualidade de mídia. Quanto maior a qualidade, mais dados serão consumidos.
- Desative o AutoPlay em “Configurações”. Assim, o Spotify só vai tocar o que você selecionar.
- Use o Wi-Fi se você estiver utilizando o app fora do país. Verifique as tarifas de roaming do seu plano de dados móveis.
- Pode ser que seu dispositivo economize dados por conta própria. Verifique o site de suporte do seu dispositivo.

## Largura de banda

O app consome largura de banda de Internet do seu dispositivo para tocar músicas sem armazenamento em buffer.

## Para reduzir o consumo de largura de banda:

- Feche outros aplicativos que usem Internet.
- Se você tiver o Premium, baixe músicas para ouvir offline.
