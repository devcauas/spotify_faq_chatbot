# Atalhos de teclado do Spotify

Atalhos de teclado pra tornar o Spotify ainda melhor.
1. No computador, abra o app Spotify ou o Web player.
2. Aperte uma dessas combinações de teclas ao mesmo tempo:
- Mac: "Command (Mac)" "Barra invertida"; "Command (Mac)" "Ponto de interrogação"; "Shift" "Barra invertida"; "Shift" "Ponto de interrogação"
- Windows: "Ctrl (Windows)" "Barra invertida"; "Ctrl (Windows)" "Ponto de interrogação"; "Shift" "Barra invertida"; "Shift" "Ponto de interrogação"
Agora você deve estar vendo uma lista com todos os atalhos, incluindo (entre outros):
- Descrição | Combinações de teclas
- Abrir busca | Cmd + K ou Ctrl + K
- Abrir Ajuda | Ctrl / Cmd + / ou Ctrl / Cmd +?
- Curtir/deixar de curtir uma música | Alt + Shift + B
- Sair | Alt + Shift + F6
- Selecionar tudo | Cmd + A ou Ctrl + A
- Filtrar | Cmd + F ou Ctrl + F
- Tocar/Pausar | Barra de espaço
- Ordem aleatória | Alt + S (Mac) Ctrl / Cmd + S (Windows)
- Repetir | Alt + R (Mac) Ctrl / Cmd + R (Windows)
- Ir para Biblioteca | Alt + Shift + 0
- Ir para Playlists | Alt + Shift + 1
- Ir para Podcasts | Alt + Shift + 2
- Ir para Artistas | Alt + Shift + 3
- Ir para Álbuns | Alt + Shift + 4
- Ir para Audiolivros | Alt + Shift + 5
- Ir para o Início | Alt + Shift + H
- Ir para Preferências | Cmd +, ou Ctrl +,
- Ir para Busca | Ctrl / Cmd + Shift + L (Mac) Ctrl / Cmd + L (Windows)
- Ir para Tocando agora | Alt + Shift + J
- Ir para Músicas curtidas | Alt + Shift + S
- Ir para Feito para você | Alt + Shift + M
- Ir para Novos lançamentos | Alt + Shift + N
- Ir para as paradas | Alt + Shift + C
- Abrir a fila | Alt + Shift + Q
- Abrir o menu de contexto | Alt + J
- Mostrar a barra lateral da tela Tocando agora | Alt + Shift + R
- Mostrar a barra lateral da Sua Biblioteca | Alt + Shift + L
- Ativar/desativar o som | mi
- Voltar para a faixa anterior | Seta para cima
- Ir para a próxima faixa | Seta para baixo
- Adicionar à biblioteca | Seta para a esquerda
- Adicionar à fila | Seta para a direita
